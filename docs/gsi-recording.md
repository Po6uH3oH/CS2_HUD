# Как записать GSI

1. Перезапустите HUD после обновления. Откройте **Настройки → Диагностика → Запись GSI**.
2. Запустите матч или демозапись **в CS2**. Для отображения этих данных в HUD выберите **Матч**. Встроенное «Демо» HUD — синтетический пример, оно не создаёт настоящих GSI-пакетов.
3. Нажмите **Начать запись GSI**. Проверьте, что счётчик пакетов растёт. Запишите 30–60 секунд нужных событий вместе с видео.
4. Нажмите **Остановить и скачать .jsonl**. Браузер сохранит файл в загрузки или предложит место. Прикрепите его к сообщению вместе с видео.

Токены, auth и пароли автоматически исключаются из всех уровней JSON. Имена и SteamID игроков остаются для сопоставления событий. Каждая строка содержит время получения `receivedAt` в миллисекундах и исходный `payload`. Запись ограничена двумя минутами или 32 МБ. До скачивания она находится в памяти: новая запись заменяет предыдущую, перезапуск сервера её очищает. Записываются входящие пакеты CS2, даже если в HUD выбран синтетический режим «Демо».

Для проблемы ослепления посмотрите колонку **Flash 0–255** в таблице диагностики во время flash. «Нет данных» означает, что поле не поступило; 0 — источник сообщает отсутствие ослепления. Если на экране игры белая вспышка, а в таблице остаётся 0 или нет данных, приложите лог: по одной картинке восстановить степень ослепления нельзя. Во встроенном демосценарии «Игровой раунд» теперь есть повторяющееся ослепление двух игроков для проверки оформления.
