# Счётчик игроков и карты серии

В **Настройки → Оформление HUD** доступны отдельные переключатели **Игроки в живых · X vs Y** и **Порядок карт · BO3 / BO5**. Первый включён по умолчанию, второй выключен, пока оператор не подготовит данные.

В **Матч → Порядок карт и FACEIT**:

1. Выберите BO3 или BO5. Добавьте карты кнопками в порядке игры; стрелка переносит карту раньше, крестик удаляет.
2. У каждой карты укажите команду, которая её выбрала, либо «Решающая». Неизвестный пик можно оставить пустым.
3. Итоговый счёт сохраняется при подтверждённом завершении карты в GSI. Старый результат можно вписать вручную в поля под названиями команд. Пустое поле означает неизвестный результат.
4. Включите показ порядка карт и нажмите **Сохранить изменения**.

Список появляется под радаром. У пика первой показывается цифра выбравшей команды: зелёная пара чисел — победа на своём пике, красная — поражение. Решающий матч и неизвестные пики имеют нейтральный цвет; счёт в них следует порядку команд в настройках. Текущая карта выделена светлой полосой. BO1 не показывает список. Пять карт помещаются над карточками игроков за счёт ограничения высоты изображения радара.

Пики и результаты привязаны к ID команд и не меняются при смене T/CT. Ручные результаты отдельных карт не пересчитывают общий счёт серии: поправьте его в полях «Карты» при необходимости. **Новый матч** очищает результаты и пики. Порядок карт остаётся для повторного использования.

FACEIT-импорт заполняет порядок карт из `voting.map.pick`, если он доступен. Владельцев пиков нужно указать вручную. GSI не сообщает, кто выбирал карты.

# Ослепление

HUD белит область текущего HP и метку на радаре согласно `state.flashed`; свежие данные наблюдаемого игрока имеют приоритет над сохранённым значением из старого пакета `allplayers`.

В записанном демо Ancient от 7 ноября 2026 GSI передавал только 0 и 1. Раньше деление на 255 делало эффект незаметным. Теперь значения 0–1 нормализуются на полный диапазон; если поток присылает значение больше 1, до сброса источника используется диапазон 0–255, включая слабый остаток ослепления. Это автоматическое определение диапазона: единица сама по себе не позволяет отличить двоичный флаг от самого слабого значения старого диапазона.

Дробные значения поддерживаются. Когда игра передаёт только 0/1, HUD показывает факт ослепления: восстановить его точную силу из двоичного сигнала нельзя. Пропавшие данные не заменяются выдуманной длительностью флешки. Логи можно собрать в **Настройки → Диагностика → Запись GSI**.
