# Счётчик игроков и карты серии

В **Настройки → Оформление HUD** доступны отдельные переключатели **Игроки в живых · X vs Y** и **Порядок карт · BO2 / BO3 / BO5**. Первый включён по умолчанию, второй выключен, пока оператор не подготовит данные.

В **Матч → Порядок карт и FACEIT**:

1. Выберите BO2, BO3 или BO5. Добавьте карты кнопками в порядке игры; стрелка переносит карту раньше, крестик удаляет.
2. У каждой карты укажите команду, которая её выбрала, либо «Решающая» (BO3/BO5). Для BO2 задайте две карты — по одному пику каждой команды, без решающей. Неизвестный пик можно оставить пустым. В поле **Стороны на старте** выберите пару CT/T: противоположная сторона второй команды задаётся автоматически.
3. Итоговый счёт сохраняется при подтверждённом завершении карты в GSI. Старый результат можно вписать вручную в поля под названиями команд. Пустое поле означает неизвестный результат.
4. Включите показ порядка карт и нажмите **Сохранить изменения**.

Карты идут одной полоской над радаром: логотип выбравшей команды, название, итоговый счёт и стрелка к следующей карте. Текущая карта белая, будущие и прошлые — серые. У пика первой показывается цифра выбравшей команды: зелёная пара чисел — победа на своём пике, красная — поражение. Решающий матч и неизвестные пики имеют нейтральный результат; счёт в них следует порядку команд в настройках. BO1 не показывает серию. BO2 и BO3 подгоняются по ширине; BO5 плавно прокручивается в обе стороны, только если не помещается. При выключенных анимациях BO5 можно прокрутить вручную. Сам радар не расширяется и не уменьшается ради серии.

BO2 играется на обеих картах: итог серии 2:0, 1:1 или 0:2. Под счётом HUD по два индикатора на команду. При уменьшении формата список карт в черновике сокращается до выбранного числа карт; проверьте его перед сохранением.

Стартовые стороны привязаны к карте и ID команды и используются при включённом автоопределении, если нет известных игроков. Сохранённые SteamID/составы имеют приоритет; после подключения смена сторон отслеживается по тем же игрокам. При позднем подключении после смены сторон используйте привязку текущего состава: стартовая сторона сама по себе не сообщает текущую сторону незнакомого игрока. Если стороны карты не заданы, используются настройки команд. В ручном режиме стартовые стороны игнорируются. См. [привязку игроков, ножевой раунд и ручную коррекцию](team-assignment.md).

Пики и результаты привязаны к ID команд и не меняются при смене T/CT. Ручные результаты отдельных карт не пересчитывают общий счёт серии: поправьте его в полях «Карты» при необходимости. **Новый матч** очищает результаты, пики и стартовые стороны. Порядок карт остаётся для повторного использования.

FACEIT-импорт заполняет порядок карт из `voting.map.pick`, если он доступен. Владельцев пиков нужно указать вручную. GSI не сообщает, кто выбирал карты.

# Ослепление

HUD белит только метку на радаре согласно `state.flashed`; карточки игроков не меняются. Свежие данные наблюдаемого игрока имеют приоритет над сохранённым значением из старого пакета `allplayers`.

В записанном демо Ancient от 7 ноября 2026 GSI передавал только 0 и 1. Раньше деление на 255 делало эффект незаметным. Теперь значения 0–1 нормализуются на полный диапазон; если поток присылает значение больше 1, до сброса источника используется диапазон 0–255, включая слабый остаток ослепления. Это автоматическое определение диапазона: единица сама по себе не позволяет отличить двоичный флаг от самого слабого значения старого диапазона.

Дробные значения поддерживаются. Когда игра передаёт только 0/1, HUD показывает факт ослепления: восстановить его точную силу из двоичного сигнала нельзя. Пропавшие данные не заменяются выдуманной длительностью флешки. Логи можно собрать в **Настройки → Диагностика → Запись GSI**.
