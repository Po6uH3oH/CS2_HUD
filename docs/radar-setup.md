# Карты: быстрый запуск

**Для Nuke ничего загружать и калибровать вручную не нужно.** В комплекте есть оба этажа и координаты из overview CS2. Готовы также Mirage, Dust2, Inferno, Ancient, Anubis, Overpass, Train и Vertigo.

1. Закройте старое окно сервера HUD и запустите `START.bat`. В OBS обновите источник «Браузер».
2. Запустите матч или демозапись в CS2 как наблюдатель. В панели HUD на странице **Эфир** включите **Матч**.
3. HUD сам определит карту. В **Настройки → Радар и карты** можно выбрать «По наблюдаемому игроку» или «Все этажи рядом», затем нажать **Сохранить изменения**.

Список «Просмотреть карту» открывает её настройки. Он не переключает текущую игровую карту. Все изображения хранятся локально; интернет во время эфира не нужен.

## Если нет игроков

Откройте «Сейчас в игре → Координаты игроков для проверки» на странице радара. Если X/Y/Z пустые, источник GSI ещё не передаёт позиции: нужен конфиг из «Подключения», перезапуск CS2 и режим наблюдателя. Загрузка другого PNG это не исправит. Игроки без позиции не рисуются. На месте смерти остаётся крест до следующего раунда. Номера маркеров соответствуют клавишам наблюдения **1–9, 0**.

Гранаты появляются по данным `allgrenades`: в полёте — значок гранаты, после положительного `effecttime` у дыма — область раскрытия. Огонь рисуется по точкам `flames`. Эти области условные, они не описывают точную геометрию дыма/огня CS2. Для плавного движения скачайте новый cfg в «Подключениях», замените старый и перезапустите CS2. HUD сглаживает маркеры за 200 мс.

Фон самого радара прозрачен; размер по умолчанию увеличен до 520. Пустые поля встроенных PNG обрезаны без изменения мировых координат. В JSON за это отвечает необязательный `viewBounds` (x, y, width, height в пикселях PNG). При замене картинки на другую удалите или обновите `viewBounds`, чтобы не обрезать нужный участок.

## Если точки смещены

Сначала откройте **Ручная настройка координат и изображений → Восстановить готовую карту → Сохранить изменения**. Эта кнопка заменяет только выбранную карту; «Отменить» возвращает несохранённый черновик.

Для Nuke исходные параметры:

| Параметр | Значение |
|---|---:|
| X начала | −3453 |
| Y начала | 2887 |
| Мировых единиц на пиксель | 7 |
| Размер изображения | 1024 |
| Поворот | 0° |
| Верхний этаж | Z ≥ −495 |
| Нижний этаж | Z < −495 |

Координаты картинки вычисляются так: `u = (X − originX) / scale`, `v = (originY − Y) / scale`. Вне диапазона Z слоя маркер не рисуется. Для особых зон перехода можно задать `regions` в JSON; их XY-полигоны имеют приоритет над общей границей высоты.

- Чтобы передвинуть все точки **вправо**, уменьшите X начала. Для сдвига на 10 пикселей исходной Nuke уменьшите X на 70. Влево — увеличьте X.
- Чтобы передвинуть точки **вниз**, увеличьте Y начала. Для сдвига на 10 пикселей увеличьте Y на 70. Вверх — уменьшите Y.
- Если в центре совпадает, а к краям расходится, проверьте масштаб и размер исходного изображения. Сверяйте минимум две удалённые точки.
- При смене геометрии карты замените соответствующий PNG и overview-параметры. Изменения сохраняются кнопкой вверху страницы.

Значения в пикселях относятся к исходному PNG, а не размеру радара на экране. Режим этажа «По наблюдаемому игроку» использует его Z; переключение обоих этажей удобно для проверки ramp и vents.
