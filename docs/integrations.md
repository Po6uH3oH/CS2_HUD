# FACEIT, OBS и локальный backend

Проверка документации: 19 октября 2026 года. Реальное подключение к аккаунту FACEIT и экземпляру OBS требует ключей и запущенных приложений. Наличие кода интеграции не означает, что эти подключения проверены на вашем турнире.

## Возможности источников

| Данные | Официальный интерфейс | Граница применения |
|---|---|---|
| Название и сведения хаба | `GET /hubs/{hub_id}` | Метаданные |
| Матчи хаба | `GET /hubs/{hub_id}/matches?type=ongoing` | REST, выбор матча оператором |
| Участники | `GET /hubs/{hub_id}/members` | Требуется пагинация больших списков |
| Команда, участники, аватар | `GET /teams/{team_id}` | Состав команды может отличаться от состава конкретного матча |
| Состав матча, BO, карты, результаты | `GET /matches/{match_id}` | Отсутствующие поля не выдумываются |
| Статистика матча | `GET /matches/{match_id}/stats` | По доступности в FACEIT; не источник покадровой телеметрии |
| Профиль игрока | `GET /players/{player_id}` | Связь игрового ID проверяется перед импортом |
| HP, позиции, оружие, таймер бомбы | Не заявлены Data API как live feed | Источник — GSI разрешённого наблюдателя |

Основание: [официальный FACEIT Data API v4](https://docs.faceit.com/api/data/) и [описание назначения Data API](https://docs.faceit.com/getting-started/Guides/retreiving-faceit-data/). Документация допускает HTTP 429; код не предполагает гарантированного числа запросов в минуту.

OBS v5 предоставляет challenge-response авторизацию, список сцен, переключение текущей сцены и включение элементов сцены. В этой реализации используются `GetSceneList`, `SetCurrentProgramScene`, `GetSceneItemList`, `SetSceneItemEnabled`. Подключение подтверждается сообщением `Identified`, а выполнение команды — успешным ответом RPC. См. [официальный протокол OBS](https://github.com/obsproject/obs-websocket/blob/master/docs/generated/protocol.md) и [README obs-websocket](https://github.com/obsproject/obs-websocket/blob/master/README.md).

## FACEIT

1. Создайте серверный Data API Key в кабинете разработчика FACEIT.
2. В разделе интеграций введите ключ, Hub ID и/или Match ID. Ключ отправляется локальному серверу один раз и хранится в локальной SQLite. Ответ API возвращает лишь признак `hasApiKey`.
3. «Синхронизировать» проверяет доступ и обновляет метаданные диагностики. Автосинхронизация делает то же с интервалом не менее 30 секунд.
4. Явный импорт матча заменяет названия, аватары, составы, FACEIT ID, BO, список карт и название соревнования. Это осознанная команда оператора; перед импортом сохраните собственный вариант в библиотеке, если он нужен.
5. Результаты FACEIT не становятся оперативным игровым счётом. При новом Match ID старый контекст, ручной счёт и счёт серии сбрасываются; первая выбранная карта становится картой нового матча. Игровая телеметрия продолжает приходить из GSI.

Клиент использует фиксированный origin `https://open.faceit.com`, таймаут 8 секунд, кеш 30 секунд, объединение одинаковых запросов, интервал между запросами минимум 350 мс и до трёх попыток при временных ошибках. `Retry-After` учитывается; длительная задержка переводит клиент в cooldown, чтобы не удерживать HTTP-запрос оператора. Кеш ограничен 100 записями. Ошибка доступа не отключает HUD.

Список матчей хаба ограничен первой страницей из 100 записей; метод участников — первой страницей из 50. Для больших хабов в текущей версии используйте точный Match ID. Секреты не включаются в публичный WebSocket, `/api/state`, диагностику и логи. API Key можно также передать серверу через `FACEIT_API_KEY`.

## OBS Studio

В OBS включите WebSocket Server и задайте пароль. Укажите адрес, обычно `ws://127.0.0.1:4455`, и пароль в панели. После подключения загрузите список сцен. Переключение сцены и включение элемента действуют на реальный OBS, поэтому проверяйте выбранную сцену в превью перед эфиром. Пароль хранится на сервере, API возвращает только `hasPassword`.

Клиент восстанавливает сетевое соединение с экспоненциальной задержкой до 30 секунд. Ошибка авторизации требует исправления пароля и повторного подключения. OBS не нужен для расчёта состояния или отображения браузерного HUD. Ручная пауза в панели управляет графикой; она не отправляет команды игровому серверу CS2.

## REST и WebSocket

Backend слушает только `127.0.0.1:3190`. `PORT` меняет порт, `DATA_DIR` — каталог данных. Запуск на произвольном сетевом интерфейсе этой версией не предусмотрен. Vite проксирует `/api`, `/ws`, `/uploads` и `/assets` к backend; после сборки backend раздаёт `dist/web`.

| Доступ | Маршруты |
|---|---|
| Публичное чтение | `GET /api/health`, `/api/state`, WebSocket `/ws` |
| GSI token | `POST /api/gsi`, JSON `auth.token` |
| Локальная панель без входа | `GET/PUT /api/settings`, `POST /api/command`, `GET /api/diagnostics`, `GET /api/gsi-config` |
| Библиотека | `GET /api/library?kind=team|match|tournament`, `POST /api/library {kind,name,data,id?}`, `DELETE /api/library/:id` |
| Изображения | `POST /api/upload {name,dataUrl}` → `{url}` |
| FACEIT | `GET/POST /api/faceit/settings`, `POST /api/faceit/sync`, `GET /api/faceit/matches`, `POST /api/faceit/import {matchId}` |
| OBS | `GET/POST /api/obs/settings`, `POST /api/obs/connect`, `/api/obs/disconnect`, `GET /api/obs/scenes`, `POST /api/obs/scene {sceneName}`, `GET /api/obs/items?sceneName=…`, `POST /api/obs/item {sceneName,sceneItemId,enabled}` |

Авторизация оператора и сессии удалены. Локальная панель имеет полный доступ сразу; проверка loopback Host/Origin сохраняется. WebSocket передаёт полный `WireSnapshot` при подключении и изменениях, команды от клиентов не принимает. Медленные клиенты отключаются при буфере более 2 МБ и могут подключиться заново.

В каталоге `data` создаётся случайный `gsi-token.txt` для приёма пакетов игры. Его значение не выводится в консоль. Старый `operator-token.txt`, если остался от прежней версии, больше не читается. Данные и секреты SQLite доступны пользователям Windows с доступом к этому каталогу; это локальное хранение, не шифрованное хранилище ключей. Не публикуйте каталог `data`. GSI-токен можно задать через `GSI_TOKEN`; `ADMIN_TOKEN` больше не используется.

Скачиваемый GSI cfg использует `buffer=0`, `throttle=0.05`, `heartbeat=1`. Для применения скачайте файл заново, замените установленный cfg и перезапустите CS2. Это запрос частоты обновлений, а не гарантия 20 полезных пакетов/с от игры.

## Файлы и состояние

Загрузка поддерживает PNG, WebP и простой SVG до 2 МБ. Sharp полностью декодирует изображение и сохраняет PNG под случайным именем; максимальные размеры 4096 × 4096. Перед декодированием SVG проходит XML-валидацию и список разрешённых элементов/атрибутов: только геометрия, локальные градиенты, маски и текст. Скрипты, внешние URL, entities, foreignObject, use и произвольный CSS отклоняются. Нераспознанные сложные SVG следует экспортировать в PNG. Исходный SVG не сохраняется и не отдаётся браузеру.

Настройки, турниры, команды, матчи и последние 250 событий хранятся в SQLite WAL. Текущее состояние CS2 не восстанавливается после перезапуска как достоверное: старт всегда LIVE с ожиданием нового пакета. Переход в DEMO выполняется только явной командой. GSI в DEMO отмечается в диагностике, но не меняет изображение; возвращение в LIVE очищает демонстрацию и ожидает новый пакет. При смене активного матча или карты сбрасывается нормализатор.

Потеря GSI останавливает отображаемые игровые таймеры по границе `staleAfterMs`. Новые достоверные пакеты восстанавливают состояние. Отсчёт ручной паузы имеет источник `manual` и не подтверждает реальную длительность паузы сервера. Диагностика содержит имена полей пакета и нормализованное состояние, без raw `auth` и без ключей.

## FACEIT: подключение по шагам и приватный Hub

1. Откройте [FACEIT Developer Portal](https://developers.faceit.com/), создайте приложение и серверный ключ Data API.
2. В «Подключениях» HUD вставьте ключ в FACEIT Data API, укажите Hub ID (идентификатор из ссылки хаба) и сохраните. Ключ хранится только локально на сервере.
3. Загрузите матчи хаба и выберите нужный. Если список пуст, укажите точный Match ID из ссылки комнаты и импортируйте матч напрямую.
4. Проверьте команды, составы, BO и карты во вкладках «Команды» и «Матч». Реальный счёт раундов получает GSI, результаты карт серии учитываются при завершении карты.

[Data API предназначен для публично доступных данных](https://docs.faceit.com/docs/data-api/). Серверный API-ключ не является входом от имени администратора приватного хаба. Видимость конкретного Hub и его матчей нужно проверить с вашим ключом: доступ к приватным данным не гарантирован. Если точный Match ID тоже возвращает 403/404, используйте библиотеку команд и ручную настройку; HUD, радар, GSI и Twitch продолжат работать независимо. Пароль администратора или стримерского аккаунта передавать не нужно. Пользовательский OAuth — отдельная интеграция, он не реализован и сам по себе не обещает доступ к закрытым матчам.
