# Автоматическое название Twitch

Откройте **Настройки → Подключения → Twitch · название трансляции**. Работает и в браузерной панели, и в Electron.

## Первое подключение

1. В [консоли Twitch](https://dev.twitch.tv/console) нажмите **«Подать заявку»** для создания приложения. Для регистрации Twitch требует подтверждённый адрес почты и двухфакторную аутентификацию.
2. Выберите тип клиента **Виден всем (Public)**. Если форма требует OAuth Redirect URL, добавьте `http://localhost`. При используемом входе по коду перенаправление не применяется.
3. Скопируйте **Client ID** в панель HUD и нажмите **Сохранить**. Client Secret, пароль и ключ стрима не нужны.
4. Нажмите **Подключить Twitch**, затем **Открыть Twitch и подтвердить**. Войдите аккаунтом владельца нужного канала и разрешите изменение параметров трансляции. Канал определяется из подтверждённого аккаунта, отдельно вводить его имя не нужно.
5. Дождитесь имени канала в панели. Подключение само по себе название не изменяет.
6. Проверьте предпросмотр, включите **Автоматически обновлять название на Twitch** и сохраните. Либо используйте **Обновить сейчас** для разовой отправки сохранённого шаблона.

Вход реализован через [официальный Device Code Flow Twitch](https://dev.twitch.tv/docs/authentication/getting-tokens-oauth/#device-code-grant-flow). Запрашивается `channel:manage:broadcast`; приложение отправляет только поле `title` в [Modify Channel Information](https://dev.twitch.tv/docs/api/reference/#modify-channel-information).

## Шаблон

```text
{team1} {score1}:{score2} {team2} | Карты {maps1}:{maps2} | {map} | {bo}
```

Пример результата:

```text
Spirit 7:4 Falcons | Карты 1:0 | de_nuke | BO3
```

| Переменная | Источник |
|---|---|
| `{team1}`, `{team2}` | Названия из вкладки «Команды», включая импорт FACEIT |
| `{score1}`, `{score2}` | Счёт по раундам на текущей карте из HUD, включая ручную коррекцию |
| `{maps1}`, `{maps2}` | Счёт серии из вкладки «Матч» |
| `{map}` | Текущая карта |
| `{bo}` | BO1, BO3 или BO5 из настроек матча |
| `{tournament}` | Название турнира |

Порядок привязан к постоянным слотам серии; соответствие team1/team2 показано в панели Twitch. Оно не зависит от расположения T/CT в редакторе и на экране. Смена сторон не переставляет команды в названии. Неизвестные переменные, незакрытые скобки, пустое название и результат длиннее 140 символов блокируют отправку. Названия команд, подставленные в шаблон, повторно как переменные не интерпретируются.

FACEIT сейчас импортирует названия и метаданные матча. Автоматическая загрузка счёта серии из FACEIT в этой функции не реализована: завершённые карты учитываются по GSI; при подключении посреди серии укажите уже сыгранные карты во вкладке «Матч». Twitch берёт единые данные HUD, отдельного расходящегося счёта для Twitch нет.

## Обновления

- Автообновление работает на сервере, даже когда страница админки закрыта.
- Отправляется только изменившийся результат, после 3 секунд стабильного состояния и не чаще раза в 15 секунд. Это локальный интервал HUD, не заявленный лимит Twitch.
- Нужны режим **Матч** и актуальная связь с CS2. Демо показывается в предпросмотре и никогда не публикуется; отсутствующий счёт не превращается в нули.
- При потере связи остаётся последнее отправленное название. При сетевых ошибках и ограничении частоты запросов выполняются отложенные повторные попытки.
- Отдельной задержки под задержку видео OBS пока нет: название соответствует состоянию, получаемому HUD. При задержанном эфире учитывайте это при включении автообновления.
- Подключение проверяется при запуске и каждый час; токены автоматически обновляются. При отозванном или истёкшем разрешении может понадобиться повторный вход.
- **Отключить** выключает автоматизацию и удаляет сохранённые локально токены. Последнее название на Twitch не изменяется. Разрешение приложения также можно отозвать в настройках подключений Twitch.

Настройки и токены хранятся локально на сервере в `data/hud.sqlite`. Токены не возвращаются в панель, снимки HUD или обычный журнал. Файл базы содержит доступ к интеграциям: не включайте его в публичные архивы проекта.

## Проверка

Шаблоны, вход по коду, проверка разрешения, обновление токенов, ограничения частоты, отключение и HTTP-маршруты проверены автоматическими тестами с подменённым API. В браузере проверены предпросмотр, ошибка неизвестной переменной и сохранение. Реальная отправка требует вашего Client ID и подтверждения владельцем канала; при разработке настоящий канал не изменялся.
