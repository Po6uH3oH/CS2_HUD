# Первый запуск CS2 HUD

## Готовое приложение — рекомендуемый вариант

1. Откройте [последний релиз](https://github.com/Po6uH3oH/CS2_HUD/releases/latest). В разделе **Assets** скачайте **CS2-HUD-0.2.0-win-x64.zip** (или ZIP с более новой версией). **Source code (zip)** — исходники, для них другой порядок ниже.
2. Нажмите на архив правой кнопкой → **Извлечь всё**. Откройте распакованную папку. Не запускайте программу внутри окна архива и не переносите один EXE отдельно от остальных файлов.
3. Дважды нажмите **CS2 HUD.exe**. Откроется панель управления и прозрачный оверлей. Node.js, Electron и зависимости уже включены: устанавливать их отдельно, открывать терминал или иметь права администратора не нужно.
4. Для OBS без отдельного окна поверх игры используйте **START_OBS.bat**. Он откроет панель в браузере; его консоль нужно оставить открытой до завершения HUD.

Поддерживается Windows 10/11 x64 (Intel/AMD). Сборка для ARM64 не выпускается. После распаковки готовый HUD запускается без Интернета; подключения Twitch и FACEIT требуют сети. EXE пока не имеет сертификата подписи издателя: Windows может показать предупреждение о неизвестном издателе. Не отключайте защиту Windows; при блокировке сообщите точный текст ошибки.

## Подключить игру один раз на новом компьютере

1. В панели откройте **Настройки → Подключения → Game State Integration → Скачать .cfg**.
2. В Steam: **CS2 → Управление → Просмотреть локальные файлы**. Откройте **game → csgo → cfg** и положите скачанный `gamestate_integration_broadcast.cfg` туда. Не добавляйте к имени `.txt`.
3. Полностью перезапустите CS2. Для внешнего окна HUD выберите полноэкранный режим в окне, без рамки. В HUD выберите **Матч** и запустите матч/демозапись в режиме наблюдателя.
4. Проверьте надпись **Игра подключена**. Для проверки оформления без игры на странице **Эфир** можно включить **Демо**. Пустой HUD до подключения GSI — нормальное ожидание данных.

Для OBS добавьте источник **Браузер**, URL `http://127.0.0.1:3190/overlay/production`, ширина **2560**, высота **1440**, поверх захвата игры. Не включайте остановку источника при скрытии, если хотите непрерывное отображение. [Настройка команд и ножевого раунда](team-assignment.md).

## Выход, обновление и настройки

Закрытие крестиком прячет панель в трей. Для полного выхода нажмите **Завершить HUD**, либо меню **H** рядом с часами → **Закрыть приложение**. Быстрые клавиши: Ctrl+Shift+F10 — HUD, Ctrl+Shift+F11 — панель, Ctrl+Shift+F12 — выход.

Готовое приложение хранит команды, настройки, загрузки и GSI-токен в **`%LOCALAPPDATA%\CS2HUD`**. Папка общая для готовых версий. Для обновления полностью закройте старую версию, распакуйте новый релиз в новую папку и запустите его: настройки сохранятся. Не запускайте две разные версии одновременно. Пользовательские иконки находятся в **`resources\app\assets\icons`**: собственные замены перенесите в новую папку релиза отдельно.

При переносе настроек со старой версии исходников: закройте оба HUD, сделайте резервную копию и скопируйте **содержимое** старой папки `data` в `%LOCALAPPDATA%\CS2HUD`. Это личная база и токены — не включайте их в архивы для других операторов. Если настройки не переносились, на новом ПК скачайте новый GSI cfg из его собственной панели.

## Если скачан архив исходников / Code → Download ZIP

Распакуйте всю папку и дважды нажмите **START_OVERLAY.bat**. Для режима OBS/браузера — **START.bat**. На первом запуске нужен Интернет: окно покажет четыре этапа — загрузка локального Node.js, подготовка установщика, установка зависимостей, сборка HUD. Дождитесь завершения. Системный Node.js и глобальный pnpm не нужны; права администратора не требуются. При следующих запусках готовые зависимости используются повторно, изменения исходников пересобираются автоматически.

Загрузки идут с `nodejs.org`, `registry.npmjs.org` и GitHub (Electron). Node.js проверяется по закреплённой SHA-256, зависимости — по lockfile. При оборванной установке повторите запуск того же BAT: неполные зависимости проверяются и восстанавливаются. Данные этой версии остаются в `data` рядом с исходниками.

## Если не запустилось

- **Архив ещё не распакован:** сначала «Извлечь всё». Все подпапки должны остаться рядом с EXE/BAT.
- **Первый запуск исходников не скачивает файлы:** проверьте доступ к трём адресам выше, свободное место и права записи в папку. Распакуйте в обычную пользовательскую папку, не в Program Files.
- **Порт 3190 занят:** полностью завершите предыдущий HUD. Новая версия не подключится молча к чужому/старому серверу.
- **Нет игроков, но панель открывается:** настройте GSI по шагам выше; проверьте Demo, чтобы отделить запуск HUD от подключения игры.
- **Окно поверх игры не видно:** используйте режим CS2 без рамки, проверьте Ctrl+Shift+F10 и монитор в меню H. OBS Browser Source работает независимо от этого окна.

Для сообщения об ошибке приложите текст и номер версии. Журналы готового приложения: `%LOCALAPPDATA%\CS2HUD\desktop-server.log` и `desktop-error.txt`. Для исходников: `data\setup.log`, `data\desktop-server.log`. Не публикуйте всю папку данных: она содержит токены.
