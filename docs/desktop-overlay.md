# HUD поверх CS2

1. Закройте старую версию HUD и запустите **START_OVERLAY.bat** из папки проекта. Откроются панель управления и прозрачное окно. Сервер запускается автоматически; если он уже работает, приложение использует его.
2. В настройках видео CS2 выберите **полноэкранный режим в окне / без рамки**. HUD покрывает выбранный монитор. Эксклюзивный полноэкранный режим не поддерживается.
3. В панели выберите **Матч**. Если GSI ещё не настроен: **Настройки → Подключения → Скачать .cfg**, положите файл в `game/csgo/cfg`, заменив старый, и полностью перезапустите CS2. Игра должна передавать данные наблюдателя.

Вход и ключ оператора не нужны. Мышь проходит через HUD в игру, само окно не перехватывает фокус.

| Действие | Клавиши |
|---|---|
| Скрыть / показать HUD | Ctrl+Shift+F10 |
| Открыть панель | Ctrl+Shift+F11 |
| Закрыть приложение | Ctrl+Shift+F12 |

Рядом с часами Windows появится значок **H**. Правой кнопкой можно выбрать монитор, открыть панель, скрыть HUD или выйти. Если горячие клавиши заняты другим приложением, используйте это меню. Закрытие окна панели сворачивает её в трей; выход из приложения находится в меню H. Приложение закрывает только тот сервер, который запустило само.

Для трансляции оставьте в OBS источник «Браузер» `http://127.0.0.1:3190/overlay/production` поверх захвата игры. Захват игры может не включать внешнее окно. При захвате всего экрана проверьте, чтобы HUD не отображался дважды.

## Как это работает

Это отдельное прозрачное окно Electron с пропуском мыши и режимом поверх окон. Оно открывает тот же локальный HUD, что и OBS. Файлы и память CS2 не меняются, инжекта нет. Основа: [прозрачные окна Electron](https://www.electronjs.org/docs/latest/tutorial/custom-window-styles) и [BrowserWindow API](https://www.electronjs.org/docs/latest/api/browser-window).

На этом компьютере зависимости уже установлены. На новом ПК сначала выполните установку и сборку из README. Если пакет Electron установлен, но бинарника нет, выполните `node node_modules/electron/install.js`. Диагностика запуска — `data/desktop-server.log` и, при ошибке окна, `data/desktop-error.txt`.

Проверены создание окна, загрузка HUD, отсутствие фокуса, always-on-top и запуск/остановка собственного сервера. Проверка поверх работающего CS2 остаётся за игровым прогоном: скрытый тест окна не подтверждает поведение игры в конкретном видеорежиме.
