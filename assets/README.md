# Ресурсы

`maps/` содержит радары девяти карт CS2, включая оба этажа Nuke, и исходные overview `.txt`. Изображения и данные принадлежат Valve Corporation; зеркало — [MurkyYT/cs2-map-icons](https://github.com/MurkyYT/cs2-map-icons). Версия исходников, URL и SHA-256 каждого файла записаны в `maps/sources.json`. Готовая калибровка находится в `packages/core/radar-presets.ts`. Интернет во время работы не требуется.

SVG-иконки оружия, оборудования и условные эмблемы созданы в `apps/web/src/overlay/icons.tsx`. Это стилизованные силуэты, а не официальные логотипы команд. Оператор может загрузить свои логотипы и заменить карты через панель; загруженные изображения сохраняются в `data/uploads` после декодирования в PNG.

Пользовательские GAME.png и TIMEOUT.png использованы как визуальные референсы и не встроены в HUD. Фон эфирных страниц полностью прозрачный.
