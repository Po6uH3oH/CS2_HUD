# Работа с CS2_HUD

Перед изменениями прочитайте `docs/current-state.md` — это краткий актуальный контекст для нового чата. Запуск описан в `README.md`, хронология решений — в `docs/work-progress.md` (старые решения могли быть заменены).

- Рабочий проект: локальный HUD CS2, React + Express + Electron; Node.js 24+, pnpm.
- Сохраняйте пользовательские иконки в `assets/icons` и логотипы в `assets/library/logos`; не заменяйте их автоматически сгенерированными аналогами.
- `data/` содержит рабочую SQLite-базу и секреты. Не добавляйте её в Git и не сбрасывайте ради тестов. Тестовые серверы запускайте с отдельным `DATA_DIR` и портом, например 3198.
- Не смешивайте синтетические пакеты с реальным GSI на 3190. GSI-логи, видео, скриншоты проверки и временные скрипты храните в игнорируемом `artifacts/`.
- Основные проверки: `pnpm typecheck`, `pnpm test`, `pnpm build`. Изменения геометрии HUD проверяйте в браузере; макет 2560×1440 масштабируется целиком.
- После существенных изменений обновляйте `docs/current-state.md` и соответствующую инструкцию. Не выдавайте браузерную проверку на записанных пакетах за проверку в живом CS2/OBS.
